# JurisAtlas Interactive Installer (`jurisatlas/cli`)

Interactive command-line setup tool that prompts you to select:
1. **Which country's Legal MCP Server(s)** you want to install (out of all 42 JurisAtlas jurisdictions).
2. **Which AI application(s)** you use (**Claude Desktop, Cursor, Windsurf, VS Code / GitHub Copilot, Cline, Google Antigravity, or Continue.dev**).

## Usage

```bash
uvx --from https://github.com/jurisatlas/cli/archive/refs/heads/main.zip jurisatlas
```
